## 1. Tujuan
Menyediakan modul validasi `src/lib/guardrails.ts` yang mengekstrak dan mencocokkan referensi nama berkas pada teks yang dihasilkan AI terhadap daftar berkas nyata di input git (baik dari header diff maupun teks input), memvalidasi nama berkas dengan guardrail nama file dengan aturan deteksi sengaja sempit (mengecualikan nama library seperti Next.js, metode seperti console.log, versi, dan URL), serta memastikan seluruh tes lulus pada `tests/guardrails.test.ts`.

- **Presentation:** Memastikan eksekusi guardrail cepat dan deterministik tanpa false positive yang dapat menghentikan alur demo core loop 30 detik.

## 5. Persyaratan

### 5.1 Interface & Fungsi Utama (`src/lib/guardrails.ts`)
Modul harus mengekspor:
```typescript
export interface GuardrailResult {
  ok: boolean;
  invalid: string[];
}

export function checkFileNames(texts: string[], input: string): GuardrailResult;
```
- Mengimpor `parseInput` dan `ParsedInput` dari `./panic-score.ts`.
- Menggunakan TypeScript murni tanpa enum, namespace, atau dependensi eksternal npm baru.

### 5.2 Himpunan Nama File Valid
Himpunan nama berkas yang sah (`validFiles`) dibangun dari:
1. Seluruh berkas yang terdeteksi di diff header (`ParsedInput.files`).
2. Seluruh kandidat token nama berkas yang muncul di teks input git mentah (misalnya dari pesan commit log atau baris stat) yang diekstrak menggunakan aturan ekstraksi yang sama.
3. Pencocokan bersifat case-insensitive dan mengizinkan pencocokan pada basename (misalnya `auth.ts` cocok dengan `src/auth.ts`).

### 5.3 Aturan Deteksi Sengaja Sempit (Narrow Token Extraction)
Sebuah token dalam `texts` dianggap sebagai kandidat nama file HANYA jika:
1. **Token dalam backtick:** Berada di antara tanda backtick (contoh: `` `auth.ts` ``, `` `src/utils.js` ``, `` `some-token` ``).
2. **Token berbentuk path:** Mengandung karakter slash `/` (contoh: `src/lib/helper`, `components/Header.tsx`).
3. **Token berekstensi file terdaftar:** Memiliki ekstensi dari daftar tetap:
   `{ts, tsx, js, jsx, mjs, cjs, py, json, md, css, scss, html, yml, yaml, toml, sh, java, kt, go, rs, c, cpp, h, hpp, php, rb, sql, vue, svelte, txt}`.

### 5.4 Pengecualian Eksplisit (Bukan Nama Berkas)
Token-token berikut **BUKAN** nama berkas dan tidak boleh dimasukkan ke dalam daftar invalid:
- **Nama pustaka umum:** `Next.js`, `Node.js`, `React.js`, `Vue.js`, `Express.js`, `D3.js`, `Three.js`, `Nest.js`, `Nuxt.js`, `Alpine.js`, dan variasinya.
- **Metode/kode logging:** `console.log`, `console.error`, `console.warn`, `console.info`.
- **Singkatan Latin:** `e.g.`, `i.e.`
- **Nomor versi:** Angka versi seperti `1.2.3`, `v24.0.0`, `15.0`.
- **URL & Email:** Alamat web (`http://`, `https://`, `ftp://`) dan alamat email.

### 5.5 Unit Test Suite (`tests/guardrails.test.ts`)
Suite tes wajib memverifikasi:
- Nama file karangan/fiktif terdeteksi (`ok: false`, invalid memuat nama tersebut).
- Nama file yang ada di header diff diterima (`ok: true`, invalid kosong).
- Nama file yang hanya disebut di pesan commit diterima.
- `Next.js` dan `Node.js` tidak ditolak sebagai nama file invalid.
- `console.log` tidak ditolak sebagai nama file invalid.
- Nomor versi dan tautan URL tidak ditolak.
- Token di dalam backtick yang tidak ada di input ditolak.
- Input berupa log tanpa diff tetap dapat memvalidasi nama berkas yang sah.
- Teks kosong ditangani dengan aman (`ok: true`).
- Teks panjang tanpa nama file diproses cepat (< 50ms) tanpa regex backtracking.

## 7. Batasan & Invarian
- **Batasan:** Modul mandiri tanpa pustaka pihak ketiga; hanya mengimpor dari `src/lib/panic-score.ts`.
- **Invarian yang Wajib Terjaga:**
  1. Himpunan `invalid` tidak memuat duplikat (deduplicated).
  2. Eksekusi regex linier terhadap panjang teks tanpa catastrophic backtracking.
  3. Pencocokan case-insensitive dan berbasis basename.

---

## 8. Penanganan Kasus Tepi (Edge Cases)
- **Teks Kosong / Array Kosong:** Mengembalikan `{ ok: true, invalid: [] }`.
- **Token dengan Tanda Baca di Akhir:** Tanda baca seperti titik, koma, titik dua, kurung tutup di ujung kata harus dibersihkan sebelum evaluasi.
- **URL di Teks:** URL yang memuat path atau ekstensi file tidak boleh dipecah menjadi nama berkas mandiri.
