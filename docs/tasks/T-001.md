## 1. Tujuan
Menyediakan modul kalkulasi murni `src/lib/panic-score.ts` yang mem-parse input git (git log standar, oneline, unified diff, atau kombinasi), mendeteksi input tak masuk akal (<20 karakter atau tanpa penanda git), menghitung Base Panic Score (0–100) secara deterministik berdasarkan 5 sinyal (dengan normalisasi diff-only 40 ke 100), mengelompokkan ke dalam pita severity (MINOR, MODERATE, MAJOR, CRITICAL), serta lulus 100% pada rangkaian pengujian unit `tests/panic-score.test.ts`.

---

## 2. Alasan & Kriteria Juri Terkait
- **Design:** Menyediakan struktur data breakdown sinyal yang transparan (`BaseScoreSignals`) untuk ditampilkan pada popover *"Why this score?"* dan penentuan intensitas warna severity badge.
- **Innovation (Unique Kernel):** Membuktikan inti diferensiasi Commit Confessional bahwa skor kepanikan dihitung secara objektif dan deterministik dari bukti nyata perubahan kode, bukan halusinasi acak model LLM.
- **Presentation:** Menghasilkan kalkulasi instan berlatensi 0ms pada sisi server sebelum panggilan AI dilakukan, menjamin responsivitas demo dan keandalan data dasar.

## 5. Persyaratan
1. **Struktur Data & Type Definitions (`src/lib/panic-score.ts`):**
   - Definisikan interface `SignalResult { points: number; evidence: string; available: boolean }`.
   - Definisikan interface `BaseScoreSignals` yang memuat 5 sinyal: `rushedCommits`, `shoutingMashing`, `repeatedFiles`, `debugLeftovers`, `diffSize`, `baseScore`, dan `dominantSignalReason`.
   - Definisikan type severity: `"MINOR" | "MODERATE" | "MAJOR" | "CRITICAL"`.
   - Ekspor fungsi `calculatePanicScore(input: string)`.
2. **Deteksi Input Tak Masuk Akal (Nonsensical Input):**
   - Validasi panjang string: tolak jika panjang `< 20` karakter.
   - Validasi penanda git: tolak jika tidak memuat diff markers (`diff --git`, `@@`, `+++`, `---`) DAN tidak memuat struktur commit log (`commit [a-f0-9]{40}` atau pola oneline `^[a-f0-9]{7,10}\s`).
   - Kembalikan objek status validasi gagal dengan pesan error spesifikasi: *"That doesn't look like commits or code changes. Paste a git diff or commit messages and try again."*
3. **Ekstraksi 5 Sinyal Deterministik:**
   - **Sinyal 1 (Rushed Commits - max 30 pt):** Deteksi commit dengan pesan singkat/generik ("fix", "wip", "test", "update", single-word, atau duplikat). Poin: `Math.round((low_effort_count / total_commits) * 30)`.
   - **Sinyal 2 (Shouting / Mashing - max 10 pt):** Deteksi huruf kapital ALL CAPS minimal 4 huruf (menghindari akronim pendek seperti "WIP"/"API") atau tanda baca berulang (`!!!`, `???`). Jika ada = 10 poin, lainnya = 0.
   - **Sinyal 3 (Repeated File Touches - max 20 pt):** Deteksi berkas yang disentuh berulang di multi-commit. $\ge 3$ commit = 20 poin; 2 commit = 10 poin; lainnya = 0.
   - **Sinyal 4 (Debug Leftovers - max 20 pt):** Deteksi baris penambahan (`+`) yang memuat `console.log`, `print(`, `debugger`, `var_dump`. Poin: `Math.min(5, debug_count) * 4`.
   - **Sinyal 5 (Diff Size - max 20 pt):** Hitung total baris berubah (tambah + hapus). `>300` baris = 20 poin; `100–300` baris = 10 poin; `<100` baris = 0 poin.
4. **Normalisasi Diff-Only:**
   - Jika input tidak memuat commit log: tandai Sinyal 1, 2, dan 3 sebagai `available: false` dengan deskripsi *"Not available (no commit messages)"*.
   - Hitung total poin sinyal 4 dan 5 (maksimal 40 poin), lalu normalisasikan ke skala 100: `Math.round(rawScore * (100 / 40))`.
5. **Klasifikasi Severity Band:**
   - MINOR: 0 – 24
   - MODERATE: 25 – 49
   - MAJOR: 50 – 74
   - CRITICAL: 75 – 100
6. **Unit Test Suite (`tests/panic-score.test.ts`):**
   - Uji skenario input nonsensical (<20 karakter dan teks acak tanpa git markers).
   - Uji input diff-only normalisasi (termasuk kasus >300 baris menghasilkan skor 50 MAJOR).
   - Uji input multi-commit lengkap dengan 5 sinyal aktif.
   - Uji singular acronym ("WIP", "API") tidak memicu shouting signal.
   - Uji batas clamping 0 dan 100.

- **Invarian yang Wajib Terjaga:**
  1. Input pengguna tidak pernah disimpan ke file disk atau log.

## 8. Penanganan Kasus Tepi (Edge Cases)
- **Input Tak Masuk Akal:** Mengembalikan error terstruktur yang dapat langsung dikonsumsi API tanpa throwing uncaught exception.
- **Diff Bersih Tanpa Debug:** Menghasilkan 0 poin debug dengan bukti kosong yang valid.
- **Diff Sangat Besar (>10.000 char):** Dipotong pada batas 10.000 karakter sebelum parsing baris jika diterapkan di layer parser.
