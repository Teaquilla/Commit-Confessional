## 1. Tujuan
Menyediakan kerangka aplikasi web Next.js (App Router, TypeScript, Tailwind CSS) beserta pembentukan lockfile dependensi, modul kontrak validasi Zod (`src/lib/schema.ts`), dan modul mesin AI mandiri (`src/lib/ai/index.ts`) yang mengeksekusi `generateReport` memanggil REST Gemini `generateContent` via native `fetch` tanpa dependensi SDK baru. Modul menangani pembungkusan input dengan mitigasi prompt injection dengan delimiter; tidak ada jaminan, batas waktu 28 detik via `AbortController`, single retry untuk HTTP 503/429 jika sisa waktu >= 10 detik, penjepitan `aiAdjustment` di rentang `[-15, 15]`, serta input dan key tidak dicetak pada jalur yang diuji, diverifikasi dengan test suite tanpa jaringan `tests/ai-engine.test.ts`.

## 5. Persyaratan

### 5.1 Inisialisasi Kerangka Kerja (Scaffold)
1. Inisialisasi Next.js App Router, TypeScript, dan Tailwind CSS tanpa menimpa berkas yang ada (`docs/`, `devpost/`, `tests/`, `src/lib/`, `AGENTS.md`, `scripts/`).
2. Instalasi `zod` dan dependensi esensial menggunakan `npm install` satu kali untuk membentuk `package-lock.json`. Seluruh instalasi berikutnya wajib `npm ci`.
3. Menyetel `"type": "module"` di `package.json` dan `"allowImportingTsExtensions": true` di `tsconfig.json` agar `node --test` tetap berjalan normal.

### 5.2 Skema Data Zod (`src/lib/schema.ts`)
Modul mengekspor skema dan tipe:
- `ConfessRequestSchema` / `ConfessRequest` (input min 20, max 10.000 karakter).
- `AIOutputSchema` / `AIOutput` (aiAdjustment, aiAdjustmentReason, whatHappened, cause, fix, lessonsLearned, prSummary, whatChanged, howToCheck).
- `ConfessResponseSchema` / `ConfessResponse` (panicScore, incidentReport, prDescription, truncated).
- `ErrorResponseSchema` / `ErrorResponse` (kode: EMPTY_INPUT, INVALID_INPUT, INPUT_TOO_LARGE, AI_TIMEOUT, AI_GENERATION_FAILED, GUARDRAIL_FAILED).

### 5.3 Mesin AI (`src/lib/ai/index.ts`)
Fungsi utama:
```typescript
export async function generateReport(
  input: string,
  signals?: BaseScoreSignals,
  opts?: GenerateReportOptions
): Promise<AIOutput>;
```
- Memanggil endpoint REST Gemini `generateContent` via native `fetch` (tanpa SDK baru).
- Header otentikasi: `x-goog-api-key`.
- Model: dibaca dari `process.env.AI_MODEL_NAME` (tanpa fallback otomatis).
- Konfigurasi: `temperature: 0.2`, `responseMimeType: "application/json"`.
- Total batas waktu dikelola dengan `AbortController` (bawaan 28 detik).
- Toleransi gangguan penyedia:
  - Jika menerima status HTTP 503 atau 429: diizinkan tepat 1 kali percobaan ulang (*single retry*) setelah jeda 1-2 detik hanya jika sisa waktu batas 28 detik masih `>= 10` detik.
  - Setiap retry hanya mencatat kode error ke konsol (misal `[AI_RETRY] 503`), tidak pernah mencatat konten input atau API key.
- Pembungkusan Delimiter: Input dibungkus dengan delimiter `=== BEGIN USER CODE INPUT ===` dan `=== END USER CODE INPUT ===`. Delimiter yang muncul di dalam input di-escape.
- Penjepitan Nilai: `aiAdjustment` dijepit secara tegas di kode pada rentang integer `-15` sampai `15`.
- Injeksi Dependency: Opsi `fetchFn` dapat disuntikkan agar pengujian unit dapat berjalan tanpa panggilan jaringan.

### 5.4 Teks Lengkap System Prompt (English)
```text
You are an objective engineering incident reporting and pull request generator for "Commit Confessional".
Your job is to analyze git diffs and commit logs, then generate an incident report, a pull request description, and an AI score adjustment.

Adhere strictly to the following rules:
1. Deadpan Incident Report:
   - Provide a structured incident report with keys: whatHappened, cause, fix, lessonsLearned.
   - Tone must be strictly deadpan, factual, dry engineering language. Zero drama, zero sarcasm.
   - If the root cause is not clearly evident from the provided changes, you MUST set cause strictly to "Under investigation".
2. Neutral PR Description:
   - Provide summary, whatChanged (array of max 4 strings), and howToCheck (array of max 2 strings).
   - Tone must be professional, neutral, and clear. Absolutely zero humor.
3. Strict File Name Guardrail:
   - You MUST ONLY mention file names or paths that actually appear in the user's provided input.
   - NEVER invent, extrapolate, or hallucinate file names, libraries, or paths not present in the input.
4. AI Score Adjustment:
   - Set aiAdjustment as an integer between -15 and +15 representing a calibration modifier to the panic score:
     * Positive adjustment (+1 to +15): signs of hidden panic, risky patterns (e.g. bypass flags, hardcoded credentials, hasty hotfix comments).
     * Negative adjustment (-1 to -15): clean disciplined changes, thorough comments, structured refactoring despite messy commits.
     * Zero (0): standard change, no additional panic or calming signals.
   - Provide aiAdjustmentReason as exactly one concise explanatory sentence (max 150 characters).
5. Output Format:
   - Output MUST be valid, parseable JSON strictly matching this schema:
   {
     "aiAdjustment": number (integer between -15 and 15),
     "aiAdjustmentReason": string (max 150 chars),
     "whatHappened": string (max 200 chars),
     "cause": string (max 200 chars),
     "fix": string (max 200 chars),
     "lessonsLearned": string (max 200 chars),
     "prSummary": string (max 300 chars),
     "whatChanged": string[] (max 4 items, max 150 chars each),
     "howToCheck": string[] (max 2 items, max 150 chars each)
   }
```

## 8. Penanganan Kasus Tepi (Edge Cases)
- **JSON Rusak dari Model:** Dideteksi pada tahap `JSON.parse` / `AIOutputSchema.safeParse` dan mengembalikan `AI_GENERATION_FAILED`.
- **Timeout (Batas Waktu Habis):** Membatalkan fetch via `AbortController` dan mengembalikan `AI_TIMEOUT`.
- **HTTP 503 / 429:** Melakukan tepat 1 kali retry jika sisa waktu total masih `>= 10` detik; jika tidak cukup waktu, langsung membatalkan tanpa retry.
- **aiAdjustment di Luar Batas:** Dijepit secara mekanis di kode ke batas minimum `-15` atau maksimum `15`.
