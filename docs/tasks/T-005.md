# T-005: Antarmuka Pengguna Dedicated Core Loop Screen (/app)

1. **Tujuan:** Membangun antarmuka pengguna `/app` sesuai spesifikasi devpost/prd.md bagian 2–5 untuk interaksi core loop yang cepat, jelas, dan siap demo.
2. **Kriteria Selesai:** Header wordmark ke `/`; textarea monospace + placeholder + disclaimer AI; 3 chip preset dari src/samples; tombol Confess (#C2410C, nonaktif jika kosong/loading, Ctrl+Enter); feedback loading 10s; Panic Score animatif naik dari 0; stempel severity 1-hue (#C2410C); dominantReason; popover 'Why this score?'; dual panel (Incident Report #F3F1EC, PR Description putih); tombol Copy ('Copied' 2s); banner pemotongan; error retry; label mock; responsif; logika murni diuji unit test.
3. **Perintah Verifikasi:** `node --test tests/ui-logic.test.ts` lulus; `npm run build` sukses; navigasi dan interaksi diverifikasi via browser/mock mode.
4. **Di Luar Scope:** Mode gelap, riwayat lokal peramban, multi-bahasa, autentikasi, database, tombol regenerate acak.
5. **Berkas:** `src/lib/ui-logic.ts`, `tests/ui-logic.test.ts`, `src/app/app/page.tsx`, `src/app/layout.tsx`, `src/app/globals.css`.
6. **Risiko:** Regresi tata letak pada layar kecil (diatasi dengan CSS stack responsif); clipboard permission pada peramban non-HTTPS (diatasi dengan cadangan execCommand).
