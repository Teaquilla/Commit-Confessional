## 1. Tujuan
Menyediakan route handler Next.js App Router `/api/confess` yang mengintegrasikan alur penuh: validasi batas ukuran body, pemotongan input > 10.000 karakter, validasi keabsahan git diff/log, kalkulasi deterministik Panic Score (5 sinyal), eksekusi AI Engine (`generateReport`) bounded oleh deadline 28 detik, validasi guardrail nama file pada seluruh teks output AI dengan batas kuota maksimal 2 panggilan AI per request, penjepitan skor akhir [0, 100], dan validasi skema respons `ConfessResponse` sebelum dikembalikan ke klien; serta menyediakan tiga berkas sample diff realistis di `src/samples/`.

---

## 2. Alasan & Kriteria Juri Terkait
- **Design:** Menjamin respons JSON terstruktur secara konsisten untuk merender panel ganda (Incident Report monospaced vs PR Description neutral) dan Panic Score bar.
- **Innovation (Unique Kernel):** Menghubungkan secara ketat heuristik Panic Score deterministik dengan kalibrasi kualitatif AI (`aiAdjustment` [-15, 15]) dan memastikan guardrail nama file mencegah halusinasi nama berkas fiktif.
- **Presentation:** Memastikan batas waktu ketat total 28 detik dengan penanganan galat yang aman dan ramah pengguna, mencegah kegagalan fatal saat demo berlangsung.

## 5. Persyaratan
1. Pisahkan logika murni ke `src/lib/confess.ts`: fungsi `handleConfess(body: unknown, deps?: ConfessDeps)` dengan `deps.generateReport` dan `deps.now` yang dapat disuntikkan.
2. `src/app/api/confess/route.ts` hanya bertindak sebagai pembungkus tipis: runtime nodejs, `export const maxDuration = 30; // hanya berpengaruh di Vercel`.
3. Alur pemrosesan:
   - Batas ukuran body mentah 100 KB; jika melampaui, kembalikan `INPUT_TOO_LARGE` (HTTP 413).
   - Input kosong atau hanya spasi: kembalikan `EMPTY_INPUT` (HTTP 400).
   - Jika panjang input > 10.000 karakter, potong ke 10.000 dan tandai `truncated: true`; jika tidak, `truncated: false`.
   - Validasi skema `ConfessRequestSchema` (dilonggarkan agar batas 10.000 tidak menolak payload sebelum pemotongan).
   - Validasi struktur git via `validateGitInput`: jika tidak valid, kembalikan `INVALID_INPUT` (HTTP 400) dengan pesan ramah PRD.
   - Parsing git via `parseInput` dan hitung Base Panic Score via `calculatePanicScore`.
   - Eksekusi AI via `deps.generateReport` dengan deadline total 28 detik.
   - Periksa seluruh teks keluaran AI (`aiAdjustmentReason`, `whatHappened`, `cause`, `fix`, `lessonsLearned`, `prSummary`, `whatChanged`, `howToCheck`) dengan `checkFileNames`.
   - Jika guardrail gagal: lakukan percobaan ulang SEKALI dengan pengingat tegas hanya jika sisa waktu total >= 10 detik DAN total panggilan AI per request belum mencapai 2 (kuota bersama dengan retry HTTP 503/429); jika masih gagal: kembalikan `GUARDRAIL_FAILED` (HTTP 502).
   - Hitung `finalScore = Math.max(0, Math.min(100, Math.round(baseScore + aiAdjustment)))`.
   - Tentukan `severity` band di kode dari `finalScore`.
   - Tentukan `dominantReason` di kode dari heuristik Panic Score.
   - Validasi data akhir dengan `ConfessResponseSchema` sebelum dikembalikan.
4. Pemetaan galat HTTP:
   - `EMPTY_INPUT`: 400
   - `INVALID_INPUT`: 400
   - `INPUT_TOO_LARGE`: 413
   - `AI_TIMEOUT`: 504
   - `AI_GENERATION_FAILED`: 502
   - `GUARDRAIL_FAILED`: 502
5. Isolasi keamanan: log konsol hanya mencatat kode galat dan jumlah percobaan; tidak pernah mencetak input pengguna atau kunci API.
6. Buat 3 berkas sample diff realistis di `src/samples/` (`late-night-hotfix.ts`, `rebase-conflict.ts`, `works-on-machine.ts`), 20-40 baris format `git log -p`, bahasa Inggris, ditulis sendiri.
7. Buat suite pengujian unit `tests/confess.test.ts` mencakup minimal 12 skenario tanpa jaringan.

- **Batasan:** Dependensi strictly dari lockfile (`npm ci`).
- **Invarian:**
  1. Berkas `.env*` tidak pernah dibuka, dicetak, atau di-commit.
  2. Input pengguna dibatasi maksimal 10.000 karakter pada pemrosesan inti dan tidak disimpan di disk/log.

  4. Kuota panggilan AI per request maksimal 2 panggilan (shared antara retry 503/429 dan retry guardrail).

---

## 8. Penanganan Kasus Tepi (Edge Cases)
- Body > 100 KB $\rightarrow$ HTTP 413 `INPUT_TOO_LARGE`.
- Input kosong/spasi $\rightarrow$ HTTP 400 `EMPTY_INPUT`.
- Input non-git/kurang dari 20 karakter $\rightarrow$ HTTP 400 `INVALID_INPUT`.
- Input > 10.000 karakter $\rightarrow$ dipotong ke 10.000, `truncated: true`.
- AI timeout (> 28s) $\rightarrow$ HTTP 504 `AI_TIMEOUT`.
- AI output JSON rusak / schema mismatch $\rightarrow$ HTTP 502 `AI_GENERATION_FAILED`.
- Guardrail nama file gagal setelah percobaan habis $\rightarrow$ HTTP 502 `GUARDRAIL_FAILED`.
- `aiAdjustment` di luar batas [-15, 15] $\rightarrow$ dijepit otomatis di kode.
